Protocol lifecycle

Simple escrow logic, intelligent judgment only where needed.

Deterministic rules control identity, deadlines, hashes and payout. GenLayer consensus is used only for the natural-language fulfillment decision.

01

Create + fund

Requester escrows GEN and commits the SLA terms.

02

Accept terms

The named provider explicitly accepts the exact terms hash.

03

Submit work

Deliverable and evidence URLs are committed with SHA-256 digests.

04

Consensus review

Validators independently judge material fulfillment.

05

Settle

SATISFIED pays the provider; UNSATISFIED refunds the requester.
